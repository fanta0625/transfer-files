# Rust + Slint 原型验证

## 2026-10-23 连接链验证

新增旧配置迁移、直连/多级配置往返、各节点密码缓存与过期测试；在真实 PTY 与 POSIX shell 中用替代 SSH 程序执行 1、2、4 节点链，验证逐级认证的地址标签。传输计划覆盖直连与 2/4 节点的上传下载顺序，保留此前文件和目录往返测试。测试替身不代表用户真实网络验收。

实机需验收：中转留空直连；添加/删除/重排中转后保存重启；认证弹窗显示正确节点；直连及多级文件/目录上传下载；中断时报告正确节点与暂存位置。当前目标仍需 Windows PowerShell。

## 远程浏览实机验收清单

请在公司 Linux 上更新、重新构建并运行：

```bash
git pull
cargo build --release --locked
./target/release/transfer-files
```

- [ ] 保存有效远程配置，右栏切换为远程；保存及重启程序不会自动连接。
- [ ] 点击“读取远程目录”，按提示核对两端指纹、输入两端密码或私钥口令；已有密钥时可免密码。
- [ ] Windows 中文、空格、单引号和 `$()` 路径能正确读取；空目录正常，文件夹优先排序。
- [ ] 成功后显示“SSH 已断开”和快照时间，跳板机上的本次内层 SSH 也结束。
- [ ] 双击目录、上级、相对路径、盘符根目录、刷新均会重新连接；失败后保留旧快照。
- [ ] 密码错误、指纹拒绝、主机密钥变化、主机不可达、路径不存在均明确失败。
- [ ] 密码框取消、网络空闲超时、关闭窗口后，本应用创建的两段会话均结束，已有个人 SSH 会话正常。
- [ ] 点击“远程选中 → 左侧”可下载文件和整个目录，完成后左栏刷新；错误日志指出失败阶段，不再误报“上传失败”。
- [ ] 使用非默认 SSH 端口、中文/空格/单引号名称测试两段传输；成功后跳板机暂存已清理，失败日志显示可能残留的暂存目录。
- [ ] 已有同名本地项目时拒绝下载；远程路径不会作为本地文件载荷对外发布。
- [ ] 密码未出现在配置文件、进程参数和任务日志中。

跳板机需允许 SSH PTY，并已有 `ssh`、POSIX shell、`stty`、`env`；Windows SSH 需能执行 `powershell.exe`。当前不支持自定义 MFA/OTP 或 keyboard-interactive，认证弹窗等待两分钟、网络空闲 60 秒中止，单次目录响应上限 16 MiB。

## 自动检查

`cargo test --locked` 使用临时目录，不修改用户实际目录。包含：

1. 中文路径、递归目录、空目录、零字节文件与同名跳过。
2. 自身/子目录复制拒绝。
3. 中途取消与临时文件清理。
4. 目标在传输中出现时无覆盖发布。
5. Unix 符号链接树拒绝。
6. Slint 无窗口 GUI 测试：异步浏览、多选、真实鼠标拖拽、双向复制、目录导航、原生文件列表载荷解析与界面截图。
7. Windows 路径解析（盘符、相对目录、UNC 根），目录协议完整性、错误和特殊字符处理。
8. Linux PTY 两端认证、主机指纹、拆分提示、取消和超时清理；嵌套 POSIX shell 用户名和 PowerShell 参数不会被拆分或执行。
9. 远程 GUI 结果发布、过期结果拒绝、失败保留快照、密码清除、认证取消、远程模式复制保护。

无窗口 GUI 测试不验证原生 X11 的 XDND 收发，也不代替 Dolphin 人工验收。

## 外部拖放适配说明

Slint 1.18.1 的内部拖放走 `DragArea` / `DropArea`。原生文件拖入使用 Winit 0.30 的 `DroppedFile` 事件。

X11 下 Winit 的事件只有文件路径，没有落下坐标；本原型通过 X11 `QueryPointer` 获取相对应用窗口的位置，映射到对应面板。多路径事件短暂聚合为同一批次。

其他平台或 X11 指针查询失败时，退回界面明确标注的“外部拖入目标”栏。Wayland 适配不计入本次验收。

GUI 向 Dolphin 拖出文件未实现，不能将内部双向拖拽通过理解为外部双向拖放通过。
