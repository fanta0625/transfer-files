# Rust + Slint 本地原型验证

## 基线

目标机由用户提供并验证：

| 项目 | 值 |
| --- | --- |
| 架构 | loongarch64 |
| 系统 | Loongnix GNU/Linux 25 |
| glibc | 2.41 |
| 桌面会话 | X11，KDE Dolphin |
| Rust | 1.95.0，host loongarch64-unknown-linux-gnu |
| Cargo | 1.95.0 |
| C 编译器 | GCC 14.2.0 |
| pkg-config | 1.8.1 |
| 已通过 | Hello World、本次讨论中的 Slint 最小窗口 |

最小窗口通过不代表完整文件管理与原生拖放已通过。以下清单用于完整原型验收。

## 本次实现的验证记录

- Windows x86_64：编译、格式检查、Clippy（所有目标，警告视为错误）通过；5 项测试通过。
- Linux x86_64（Debian / WSL）：编译及 6 项测试通过，包括 Unix 符号链接用例；测试目录脚本语法及实际执行通过。
- `loongarch64-unknown-linux-gnu`：`cargo check --locked --offline --target loongarch64-unknown-linux-gnu` 通过。交叉检查使用 Rust 1.99.1 和目标标准库，允许 pkg-config 使用主机库元数据；它不包含龙芯目标链接或实机运行验证，也不等于验证过目标机 Rust 1.95 的完整构建。
- Linux 无窗口软件渲染截图已经检查，双栏、文件行和任务结果正常显示。
- 原生 X11 / Dolphin 拖入代码已接入，仍需在用户的 LoongArch64 / KDE X11 桌面实测。
- SSH、真实远端目录和 GUI 拖出到 Dolphin 不在本次实现范围内。

## 运行准备

在项目根目录执行 `bash scripts/create-demo.sh`，复制输出的 `cargo run --locked -- ...` 命令启动原型。所有操作先在此隔离测试目录中完成。

## 验收清单

- [ ] 编译通过，窗口打开，无持续错误输出。
- [ ] 中文显示、输入法、复制粘贴、缩放与窗口关闭正常。
- [ ] 初始左右目录与命令行指定的一致。
- [ ] 路径输入后回车与“前往”均可导航；不存在路径有错误日志，并保留旧目录。
- [ ] 双击目录进入，“上级”返回，“刷新”显示外部新增文件。
- [ ] 目录优先并按名称排序；大小与 UTC 修改时间显示正常。
- [ ] 多选、全选、清空选择正确，已选项目数量准确。
- [ ] 从左到右拖拽已选多项，一次复制全部；从未勾选行拖拽仅复制该项目。
- [ ] 从右到左复制也正确；双向按钮可作为拖拽之外的入口。
- [ ] 中文及空格路径、嵌套目录、空目录、零字节文件内容正确。
- [ ] 从 Dolphin 多选文件及目录拖到右栏，结果写入右栏当前目录；原文件保留。
- [ ] Dolphin 拖到左栏，结果写入左栏当前目录；落在子目录行上仍写入本栏当前目录。
- [ ] 窗口缩放或有桌面缩放比例时，外部拖入的左右栏判定仍正确。
- [ ] 复制同名文件/目录会跳过，不改变现有目标内容，不合并目录。
- [ ] 复制目录到自身或其子目录被拒绝。
- [ ] 符号链接与含链接的目录树被拒绝，不递归跟随链接。
- [ ] 大文件复制时进度更新、窗口响应正常；取消后无当前文件 `.part` 残留，之前已完成文件保留。
- [ ] 复制期间改变浏览目录，不改变当前任务目标。
- [ ] 权限不足、不可访问源文件或不支持硬链接的目标产生可读错误。
- [ ] 批次运行时新拖入不形成第二个并发批次；取消后可重新发起。
- [ ] 关闭正在复制的窗口会请求取消并等待后台清理结束。

## 自动检查

`cargo test --locked` 使用临时目录，不修改用户实际目录。包含：

1. 中文路径、递归目录、空目录、零字节文件与同名跳过。
2. 自身/子目录复制拒绝。
3. 中途取消与临时文件清理。
4. 目标在传输中出现时无覆盖发布。
5. Unix 符号链接树拒绝。
6. Slint 无窗口 GUI 测试：异步浏览、多选、真实鼠标拖拽、双向复制、目录导航、原生文件列表载荷解析与界面截图。

无窗口 GUI 测试不验证原生 X11 的 XDND 收发，也不代替 Dolphin 人工验收。

## 外部拖放适配说明

Slint 1.18.1 的内部拖放走 `DragArea` / `DropArea`。原生文件拖入使用 Winit 0.30 的 `DroppedFile` 事件。

X11 下 Winit 的事件只有文件路径，没有落下坐标；本原型通过 X11 `QueryPointer` 获取相对应用窗口的位置，映射到对应面板。多路径事件短暂聚合为同一批次。

其他平台或 X11 指针查询失败时，退回界面明确标注的“外部拖入目标”栏。Wayland 适配不计入本次验收。

GUI 向 Dolphin 拖出文件未实现，不能将内部双向拖拽通过理解为外部双向拖放通过。
